# AI Video Creative Portfolio — Toluwani Oyebode

A GitHub Pages portfolio for six original product-led short-form advertising concepts, with storyboards and a Loom introduction script.

## Current status — honest production tracking

The six creative concepts and storyboards are prepared. **The six finished video exports and Loom recording are not yet produced.** The site intentionally does not present concept placeholders as completed client-ready videos.

## Projects

1. The Serum Edit — luxury serum product film (15s)
2. Everyday Shield — sunscreen campaign (15s)
3. After Dark — fragrance film (15s)
4. The Reset — facial cleanser film (15s)
5. Soft Focus — moisturizer film (15s)
6. The Daily Ritual — multi-product skincare brand film (20s)

Each has a shot list, visual direction, on-screen copy, sound notes and generation prompts in `storyboards/`.

## Brand-safety / job brief compliance

- Product-only AI imagery and environments.
- No AI-generated human faces, skin, models or realistic human imagery.
- Use real brand-provided assets for any human or skin imagery if a future brief requires it.
- No unverified medical, clinical or efficacy claims.
- Final video target: 1080×1920, 9:16, H.264 MP4, platform-ready audio and captions.

## Finish production

1. Connect a video generation tool (Higgsfield is the planned tool) and an editor such as Adobe Premiere/Express.
2. Generate product/environment shots using each storyboard's prompts. Use fictional unbranded packaging unless authorized product assets are supplied.
3. Edit each sequence, add sound design and text, review continuity and export MP4s.
4. Place exports in `media/` using the exact filenames below:
   - `video-01-serum.mp4`
   - `video-02-sunscreen.mp4`
   - `video-03-fragrance.mp4`
   - `video-04-cleanser.mp4`
   - `video-05-moisturizer.mp4`
   - `video-06-brand-film.mp4`
5. Record the Loom using `loom-script.md`; add its share URL to the Introduction section in `index.html`.

## Publish with GitHub Pages

In the repository: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)** will publish the repository root, not this subfolder. To publish this portfolio as its own site, either configure Pages to deploy this folder via a GitHub Actions workflow, or move/copy these site files to a dedicated repository root. The intended project URL if hosted from this folder in the existing Projects Pages site is `https://toluwanioyebode.github.io/Projects/AI-Video-Portfolio/`.
