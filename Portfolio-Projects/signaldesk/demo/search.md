# Search that explains itself

## Lexical retrieval

BM25 ranks documents using term frequency, inverse document frequency and a length normalization factor. Repeating a query term has diminishing returns. A rare term can provide a stronger signal than a term that appears in every chunk.

## Chunking and citations

Split a document around headings and manageable blocks of text. Keep source line numbers alongside each chunk so a result can be traced back to the original text. A snippet is an excerpt, not an answer generated by a language model.

## Limits

Lexical search matches words. Without stemming, "retry" and "retries" differ. It does not infer synonyms or understand meaning like an embedding model. Evaluate retrieval with relevance judgments before claiming search quality on a real corpus.
