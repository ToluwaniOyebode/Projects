# Preparing an engineering portfolio

## Show working behavior
A useful project can be run from a short README. Provide sample data, clear setup instructions, and meaningful tests. Show what happens when validation fails as well as when everything works.

## Discuss tradeoffs
Explain why a local SQLite database fits a single-user application. Discuss what changes for multiple users: authentication, permissions, deployment, migrations and backups. A deliberate small scope is easier to explain than unsupported production claims.

## Demonstrate evidence
Use screenshots from a running application. Report test results that were actually measured. Keep synthetic demonstration data clearly labeled and avoid claiming that a hand-written scoring rule is a trained machine learning model.
